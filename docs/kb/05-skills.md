## 技能是什么

技能是马娘在比赛中满足特定条件时发动的特殊效果。获取方式：

- 育成中或育成完成时，消耗技能点（スキルポイント / SP）学习。
- 育成中通过「提示（ヒント）」获得学习资格，**提示等级最高 Lv5**；等级越高，学习该技能所需的 SP 越少。

## 五种效果类别

| 颜色 | 效果方向 |
| --- | --- |
| 绿 | 提升自身能力（能力上升类 buff） |
| 黄 | 提升速度 / 加速力 / 敏捷性 |
| 蓝 | 回复耐力、降低耐力消耗 |
| 红 | 降低对手的能力 / 速度 / 加速力 / 耐力（干扰） |
| 紫 | 使自身能力下降（负面效果） |

同一系统还有效果更强的**稀有技能（レアスキル）**。

## 负面技能（バッドスキル）

- 属于紫色（紫）类，效果是「在特定条件下变得更不利」。
- 触发场景：比赛中大败等。
- 可以消耗 SP 消除；部分负面技能消除后还能额外获得一个绿色 buff 技能。
- 少数负面技能无法消除。

> 这一点对助手很实用：用户问「为什么我练出来的马娘有个紫色技能」时，答案是比赛中大败随机获得，可以花 SP 洗掉。

## 固有技能（固有スキル）

- 马娘初始即拥有的技能，效果因角色而异。
- 育成中的事件可以提升其技能等级与效果。
- 发动时有专属切入演出（cut-in）；初始 ★3 的演出比 ★1 / ★2 更华丽。
- 可以通过继承让别的马娘获得，但**按普通技能处理**：失去等级概念，效果也比原版固有技能略低。

## 进化技能（進化スキル）

- 2023-02-22 更新追加。
- 育成中满足特定条件，可以在育成完成时把指定的稀有技能转换成进化技能。
- 分两类来源：
  - 马娘固有：对象是该马娘初始就持有提示的稀有技能。
  - 剧本固有：对象主要是剧本中、或剧本链接友人协助卡给出提示的稀有技能。
- 同一个稀有技能存在多个进化方向时（或与剧本固有重复时），**只能选一个**；也可以选择不进化、保留原稀有技能。
- 进化后通常是效果量提升或发动条件放宽，但也有「条件更严、效果更强」以及「效果完全改变」的情况。
- 即使是同一个稀有技能，不同马娘、不同剧本的进化技能名称与改动也不相同。

## 简中技能页的触发条件记法（S8）

BWiki 的简中技能页以 `简/<技能名>` 命名，页面本身通常只记录两类信息：技能 ID 与「简中触发条件」。效果数值、持续时间、冷却由页面模板或数据页加载，不在页面正文里。

本节记录两个示例：**小心波澜炮！**（ID 10071）与**热血进化的骑乘！**（ID 105302111）。它们只用于说明页面如何记录触发条件，不代表完整技能库。

| 技能 | ID | 页面记录的触发条件 |
| --- | --- | --- |
| 小心波澜炮！ | 10071 | 行进距离 ≥50% 且 ≤60%，名次 >50% |
| 热血进化的骑乘！ | 105302111 | 条件 1：居中，终盘前四分之一随机位置，名次 ≥40%；条件 2：发动第一段技能，剩余距离 199～201m |

页面用「行进距离百分比」「名次百分比」表述；百分比的基准（全程距离 / 参赛人数）页面没有展开，引用时不要自行换算。这些是**发动条件**，不是效果量。

## 与协助卡的关系

协助卡提供的主要价值之一就是技能提示（见 [01-game-overview.md](./01-game-overview.md)）：卡片在育成中给出提示，降低学习成本；友情训练则负责属性。评估一张协助卡时，技能提示与属性加成需要分开看。
