## 五项属性

育成期间提升的属性固定为五项：

| 日文 | 英文 | 简中（已核对） | 赛道上的作用（定性） |
| --- | --- | --- | --- |
| スピード | Speed | 速度 | 决定最高速度上限 |
| スタミナ | Stamina | 耐力 | 决定能维持速度的耐力 |
| パワー | Power | 力量 | 加速与对抗、坡道表现 |
| 根性 | Guts | 毅力 | 终盘僵持、体力见底时的表现 |
| 賢さ | Wit | 智力 | 技能发动率、位置取位等 |

> 简中译名取自简中服 `master.mdb` 文本表，方法见 [08-glossary.md](./08-glossary.md)。注意 `スタミナ` 官方译作**耐力**。

五项属性的**用途差异**属于机制通识（B 级）；但「某属性多少点等于多少收益」是数值问题，本知识库不含。

## 训练机制（定性）

育成主界面的训练菜单按属性分成五类，每类训练同时给出主属性与副属性，并消耗体力。各菜单的产出方向（C 级，来源 S3，国际服 URA / Unity Cup 版本）：

| 训练 | 主属性 | 同时产出 |
| --- | --- | --- |
| 速度训练 | スピード | パワー、技能点、消耗体力 |
| 耐力训练 | スタミナ | 根性、技能点、消耗体力 |
| 力量训练 | パワー | スタミナ、技能点、消耗体力 |
| 毅力训练 | 根性 | スピード、パワー、技能点、消耗体力 |
| 智力训练 | 賢さ | スピード、技能点、**回复体力** |

智力训练是唯一回复体力的训练项，这一点在 S3 的表格中可以确认；其余菜单的体力变化为负。

## 影响单次训练收益的因子

S3 给出的收益构成（C 级，公式仅作结构参考，不代表当前系数）：

1. **基础训练值**：随训练设施等级上升。
2. **协助卡加成**：属性加成、友情训练（同属性多张卡叠加时收益最大）。
3. **干劲（やる気）**：以系数乘算，见下节。
4. **训练效果（Training Effectiveness）**：协助卡属性，直接乘算。
5. **在场人数**：同场训练的马娘数量越多收益越高。
6. **成长率（Uma Growth）**：马娘自身的属性成长加成。

社区常用策略（B/C 级，属经验而非规则）：把同属性协助卡堆叠以触发友情训练；再混入「高训练效果、低专属性」的协助卡（俗称 roam 卡）利用训练效果加成。这类策略会随卡池变化，助手回答时应提示「取决于当前卡池」。

## 体力（体力）

- 训练与比赛都会消耗体力。
- 体力越低，**训练失败率越高**；训练失败会导致属性下降等负面结果。
- 主要恢复手段：休息、外出；部分事件也会增减体力。
- 智力训练可以回复体力（见上表）。

## 干劲（やる気）

- 影响训练的成长率，也影响比赛表现。
- 主要提升手段：休息、外出；事件会使其上下浮动。
- 干劲档位与系数（C 级，来源 S4，已归档的国际服数值，仅作量级参考）：

| 干劲（简中服官方译名） | 系数 |
| --- | --- |
| 极佳（絶好調 / Great） | 1.04 |
| 上佳（好調 / Good） | 1.02 |
| 普通（普通 / Normal） | 1.00 |
| 不佳（不調 / Bad） | 0.98 |
| 极差（絶不調 / Awful） | 0.96 |

> 这组系数只用于说明「干劲是 0.96～1.04 的乘算因子」，**具体数值以游戏内为准**。

## 状态（コンディション）

- 分两类：对育成有利的**良好状态（橙）**、不利的**负面状态（青）**。
- 主要在事件中随机获得；部分马娘在特定事件中必定获得专属状态。
- 事件获得的负面状态，可能通过「医务室」或外出（参拜）去除。
- 具体状态列表、简中名称与页面给出的数值见 [09-status-effects.md](./09-status-effects.md)。

## 属性在比赛中如何生效（C 级，仅供参考）

来源 S4（已归档）给出的分层，可用于向用户解释「为什么面板数值不等于赛道数值」：

- **原始值（Raw Stat）**：属性页面显示的数字。
- **基础值（Base Stat）**：原始值叠加剧本加成后，再乘干劲系数。
- **最终值（Final Stat）**：基础值再叠加赛道修正、场地修正、技能修正等。

S4 记载的几个具体项（仅代表其版本）：

| 项 | 内容 |
| --- | --- |
| 育成模式加成 | 育成模式下每项属性 +400（Single Mode Modifier） |
| 赛道阈值修正 | 部分赛道有 1～2 项「阈值属性」，按该属性每 300 点（上限 900）给出速度系数 0.05 / 0.10 / 0.15 / 0.20 |
| 场地修正 | 草/泥、良/稍重/重/不良会给出速度与力量的负向修正 |
| 跑法适应性对智力的修正 | 依跑法适应性等级乘算（前端 1.1 至最低 0.1 量级） |
| 属性上限 | 某剧本（Grand Concert）起可突破 1200，超过 1200 的部分按半值计入；绿色技能不受半值影响 |

> 上表**不可直接用于回答简中服问题**。S4 明确标注已归档，且简中服剧本进度落后。若用户需要精确计算，应等 `catalog` 模块接入真实 `master.mdb` 后再提供。
